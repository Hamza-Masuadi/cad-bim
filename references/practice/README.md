# Practice guides: index

How a senior drafter, BIM coordinator or interior designer decides what to draw or model, how to do it, and how to judge the result. Read the guide for the task before planning a job. The project's own standard always overrides these defaults. Building-code compliance is the user's responsibility; numbers from codes carry their source and jurisdiction. Sources are in `_SOURCES.md`.

Open only guides for the app the job runs in: "AutoCAD" and "Revit" guides belong to that app alone. In a "Both" guide, skip the sections headed for the other app.
